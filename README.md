# おえかき暮らし

自分で描いた相棒と暮らす、お絵かき＋お世話のブラウザゲーム。

- **いまの版**：v0.1.0（マイルストーン1：一通り動く版、2026-11-09）。ゲームの中にあるものはすべて遊べます。絵と音の一部は仮素材です（下の「仮素材」）。
- **公開**：GitHub Pages（`main` ブランチをそのまま配信。ビルドなし）

## 動かし方

ES Modules を使っているので、ファイルを直接開かずに、サーバー経由で開いてください。

- `npm run serve`（または `python3 -m http.server`）→ 表示された URL を開く
- URL に `?debug` を付けると、設定のいちばん下に開発用ボタンが出ます
- three.js は `vendor/` に同梱しているので、ネットにつながなくても動きます（字体だけ Google Fonts から読みます）

## 遊べるところ

**はじめかた**
- 名前と性格を決める（あとから変えられない）
- 絵は、自分で描くか、魔法のペンにおまかせ
- 最後に「この子でいい？」の確認画面
- セーブを貼りつけて続きから始めることもできる

**画面の上（HUD）**
- 左上：コイン、日数、思い出
- 中央：場所の切り替え（おへや・カフェ・コンビニ）
- 右上：設定
- ステータス欄を押すと、相棒の情報と「手直し」が開く（3日目までは白紙から描き直せる）

**おへや**
- バッグ：コンビニで買ったごはんと、おもちゃで遊ぶ
- お風呂
- おやすみ（次の日へ）
- お部屋：模様替え（ポスターを描く、引っ越し先を見る）
- 相棒をタップすると反応する。左右にこするとなでる

**カフェ**
- メニュー → 作る → 運ぶ → 右下の「つぎのお客さま」
- メニューにない種類は、新しく描いて追加できる
- 自分で描いた料理は、特別な反応と、はじめて出したときのボーナス
- お店：お店を広げる（3段階）

**コンビニ**
- ごはんとおもちゃを買う
- 新しい商品を描いて増やせる（自分で描くと割引）
- おもちゃは種類（ボール・猫じゃらし・ぬいぐるみ）で遊び方が決まる

**設定**
- 音、音量
- ハラハラモード（次の日から反映）
- セーブの書き出し・読み込み（文字のコピーと貼りつけ）
- 最初からやり直す（すべて消える）

**ハラハラモード**
- コインと仲よし度の上がり方が1.5倍
- 放っておくと、よごれ → 具合が悪い → お別れ
- さみしいと、外へ出てしまう
- 試作用に時間は短め（病気まで2分、お別れまで1分半）

## ミニゲーム

すべて共通の枠（`{ done, quality }` を返す）で動きます。
- 長押しとダブルタップは使いません。
- 出来ばえが「よい」だと、少し多めにもらえます。

| ミニゲーム | ファイル | 遊び方 | 「よい」の条件 |
|---|---|---|---|
| 料理（飲みもの） | `js/mg-cook.js` | ドラッグで注ぎ、線のあいだで離す | 70〜88%で止める（こぼすと失敗） |
| 料理（ごはんもの） | 同上 | 動く目もりを、まんなかでタップ ×3 | 2回以上ぴったり |
| 料理（しょっぱいもの） | 同上 | 点線に沿ってスワイプ ×3 | 2回以上まっすぐ |
| 料理（甘いもの） | 同上 | タップでトッピング ×6 | いつも「よい」 |
| お風呂 | `js/mg-bath.js` | ぬらす → 泡 → 流す → 水滴を吹きとばす | 40秒以内 |
| ボール | `js/mg-play.js` | 引っぱって離して投げる。待っている相棒がキャッチ ×3 | キャッチ2回以上 |
| 猫じゃらし | 同上 | 振って、ぴたっと止めると飛びつく ×5 | 大ジャンプ3回以上 |
| ぬいぐるみ | 同上 | わたして、ハートが大きいときにタップ ×4 | ぴったり3回以上 |
| 迎えに行く | `js/mg-chase.js` | かくれんぼ。3回見つける | 外れ2回以内 |

料理の「よい」はチップ（売上の20%）になります。遊び・お風呂の「よい」は、ごきげんと仲よし度に効きます。

## 開発用ボタン

URL に `?debug` を付けたときだけ、設定のいちばん下に「開発用」が出ます。
- 逃げた状態にする
- 具合が悪い状態にする
- よごれた状態にする
- コイン＋1000
- 次の日にする

## 仮素材

- **魔法のペンの絵**：`assets/pen/`
  - 相棒（猫10種・人型3種）と料理12種は、現行版の絵を流用しています。
  - ポスターとおもちゃは、仮に描いた簡単な絵です。
  - 同じ名前のファイルで置き換えれば差し替わります。
- **3Dの部屋・カフェ・コンビニ**：箱と円柱だけの仮の形です。
  - 引っ越し先の4軒は、壁と床の色と広さだけが違います。
  - お店の3段階は、見た目が少し増えるだけです。
- **音**：効果音はその場で合成しています（`js/audio.js`）。BGMはまだありません。

## 開発

```
npm test                                         # ルール・通しプレイ・ミニゲームの自動確認
```
